# Go-live status

This package is the most complete local build currently available without user-owned credentials.

## Already done
- real login
- real local database
- real backend
- real webchat channel
- sales, admin, finance, pricing and knowledge modules
- source library and uploads
- backup, version and health endpoints
- integration-ready routes for OpenAI, WhatsApp and Stripe

## Still requires your own accounts
- OpenAI API key
- WhatsApp Business Platform credentials
- Stripe keys and webhook secret
- public hosting/domain/HTTPS if you want to deploy it online
