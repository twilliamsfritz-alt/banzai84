# Objection handling

## "I already use WhatsApp"
Perfect. This does not replace WhatsApp. It gives you a system around it so you can respond, quote, follow up and control the operation better.

## "I don't want something complicated"
The pilot is intentionally simple. We start with one workspace, one team, one flow and only the modules you need.

## "What if it sounds robotic?"
The response profile is editable. The assistant is tuned to sound warm, clear and human, and every workspace can adjust its tone.

## "I need to think about it"
No problem. Let me show you exactly how it would work in your business in 10 minutes and then you decide if it is worth piloting.
